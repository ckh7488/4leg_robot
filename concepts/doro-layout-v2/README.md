# 도로롱 전체 구조 탐색 V2

[그림 중심 검토 자료](index.html). 2026-10-24 사용자의 최신 지시: 도로롱 외형을 기준으로 물리적으로 구현할 구조를 검토하고, 크기와 가격은 당장의 제약으로 두지 않는다. 네 발 보행·실제 두 발 보행·넘어짐 복구·초기 유선 전원과 당김 측정은 유지한다.

이 폴더의 `design.json`이 V2 가정 원본이다. 앞선 `short-limb-v1`과 기존 루트 XL330 구현은 별도 기록으로 보존한다. V2는 제작용 CAD나 보행 시뮬레이션 완료 상태가 아니다.

## 제안하는 기구 구성

- 속이 빈 큰 머리, 독립 머리 기울기 1축. 무거운 전자회로는 몸통에 둔다. 머리/얼굴 질량 650g은 배분 가정이다.
- 뒷다리마다 골반 3축·무릎 1축·발목 2축, 앞다리마다 어깨 2축·팔꿈치 1축. 보행 18축 + 머리 1축 = 19축 검토안. 17축/둥근 수동 좌우 발목 대안도 남긴다.
- 뒷다리는 140+150mm, 앞다리는 140+160mm의 실제 링크를 접어 몸통/외피 안에 숨긴다. 보이는 팔다리 길이와 관절 사이 길이를 구분한다. 외피 개구부와 전 범위 노출 길이는 미설계다.
- 무릎 모터를 허벅지 위쪽에 두고 같은 링크 안의 벨트로 전달한다. 종아리 모터 두 개와 두 막대가 두 축 발목을 움직이는 첫 연결 치수안을 검토한다. 출력축 각도 센서와 하중 지지 베어링이 필요하며 규격은 미선정이다.
- 몸통 골반/어깨를 연결하는 측판·가로 보가 하중을 받고, 외피는 분리 정비한다. 재료·두께·베어링/축 규격·냉각 성능은 아직 확정하지 않는다.

## 질량과 크기의 의미

두 발 기준 전체 높이 692mm, 머리 공간 폭 460mm. 몸통 공간의 바닥선 아래 높이는 기준 자세에서 162mm다. 움직일 때의 외형 길이 또는 제작 가능한 내부 공간을 증명한 수치가 아니다.

기성 모터 질량 참고 배분은 AK70-9 V3 14개, AK60-6 V3 4개, AK45-10 V3 1개로 9.342kg. 구조·외피·전자회로·배선·여유분 5.65kg을 더하면 14.992kg이다. 실제 부품 배치와 질량 산출이 아니며 어떤 모터도 구매 대상으로 선정하지 않았다. 배터리/외부 전원 장치는 제외했다. 머리 모터 참고품은 24V라 48V 몸체 전원과의 변환 또는 모델 변경이 필요하다.

공시 정격·최대 토크는 별개다. 추가 벨트 감속의 토크 계산은 효율 90% 가정이며 출력축 수용 능력이나 연속 운전 정격을 보증하지 않는다. 한 발 수직 지면 반력 기여분은 전체 균형을 만족하는 역동역학이나 가속·충격 하중 계산이 아니다.

## 실행과 검사 범위

저장소의 `requirements-sim-lock.txt` 환경에서 다음을 실행한다.

```sh
python concepts/doro-layout-v2/study.py
python concepts/doro-layout-v2/study.py --render
python concepts/doro-layout-v2/verify_study.py
```

첫 명령은 JSON/HTML을 재생성한다. 두 번째는 정적 배치 그림과 그 그림용 XML도 생성한다. 세 번째는 선택 발목의 30각도와 몸체 기준 자세의 발목 각도 2개를 MuJoCo의 독립 도형 거리 함수로 검사한다. XML에는 관절 제어·자유몸체·접촉 동역학이 없고, 계산한 위치에 고정한 도형만 있다. `mj_step`을 호출하지 않는다. 두 발 서 있기, 보행, 자세 전환, 자가복구를 검증하는 모델이 아니다.

`study.py`는 다음을 계산한다.

1. 앞다리의 이상적 좌우·앞뒤·팔꿈치 축, 뒷다리의 시상면 두 링크와 발목 보정으로 지정 발 위치를 푼다. 골반 축이 한 점에서 교차한다고 가정한다. 실제 19축의 모터/베어링 오프셋과 전체 공간 범위를 모델링한 것이 아니다.
2. 역기구학 해를 순기구학으로 확인하고 링크 길이, 발목의 자세 보정, 지정 관절 범위를 검사한다. 앞다리 평면은 ±90° 이내의 작은 좌우 각도 표현을 선택한다. 처음에는 같은 평면의 다른 표현인 약 ±162°가 선택되어 가정 범위를 벗어났으며, 작은 각도 표현으로 수정했다. 관절 제한을 완화해서 감추지 않았다.
3. 두 발/네 발 기준 자세와 몸통 각도·높이의 16조합을 검사한다. 앞발까지 바닥에 둔 16조합은 자세 전환 궤적이 아니다. 8조합만 지정 발 위치와 가정 범위를 만족한다.
4. 질량점 배분 합계와 부품별 질량 예산 합계를 독립적으로 대조하고 무게중심을 계산한다. 두 발 지지 사각형 안의 무게중심 투영은 필요 조건만 확인한다. 실제 접촉 힘, 여유, 안정성은 미검증이다.
5. 옆/등 외피 접촉 자세에서 어깨-바닥 거리와 장애물을 무시한 최대 팔 도달 거리를 비교한다. 실제 접힌 팔다리의 접촉, 충돌 없는 팔 경로, 마찰, 복구 모멘트는 생략한다.

`ankle_linkage.py`는 별도의 두 막대 발목 첫 치수안을 검사한다. 회전 팔 길이를 바꾸면 중립 자세에서 필요한 막대 길이도 다시 정한다. 발판 회전 순서는 앞뒤 축 회전 후 좌우 축 회전이다. 두 모터의 각도를 고정 막대 길이 조건에서 풀고, 길이 잔차와 해석 미분/중앙 차분을 비교한다. 힘은 가상 일의 관계 `관절 토크 = Hᵀ × 모터 토크`를 사용한다. 링크 비율을 일정한 추가 감속비로 간주하지 않는다.

막대와 모터 원통 사이만 검사한다. 막대 중심선의 점들을 원통의 정확한 부호 있는 거리식에 대입한 뒤, 표본 간격의 절반과 막대 반지름을 빼서 전체 막대 길이에 대한 보수적인 간격 하한을 구한다. 양수이면 **그 자세의 그 막대/모터 쌍**만 겹치지 않는다는 뜻이다. 회전 팔·축·베어링·관절 연결부·중심 지지 구조·다른 다리·껍데기 간섭은 제외했다. 유한 각도 표본 사이의 연속 경로도 미검증이다.

50mm 회전 팔 후보의 막대 길이는 중립에서 약 151.16mm다. 두 모터 하우징 중심을 좌우 ±55mm에 둔 초기 배치는 30표본 중 24개만 막대 간격 하한이 양수였다. 회전 팔 설치 평면은 ±100mm를 유지하고 하우징 중심만 ±40mm로 옮기면 30표본 모두 양수이며 최소 하한 4.09mm다. 독립 MuJoCo 검사 최소는 4.47mm다. 하우징 외측에서 회전 팔까지 약 35.5mm의 축 연장이 생기므로 별도 지지 베어링을 설계해야 한다. 이 공간과 축 하중을 무시한 완성도 주장으로 사용하지 않는다. 압축을 받는 막대의 좌굴도 미검증이다.

발목의 앞뒤 8N·m/좌우 6N·m 예시는 중립에서 모터 토크 크기 약 7.33/1.46N·m이나, 30표본 중 최대는 10.29N·m다. 참고 모터 공시 정격 8.5N·m를 넘으므로 중립 값만 보고 연속 유지 가능으로 판단하지 않는다. 같은 하중의 최대 막대 축력 크기는 약 308N다. 실제 필요 하중·발열/지속 시간·추가 감속 또는 모터 변경은 후속 선정 항목이다.

전체 외피는 타원체 공간으로 표현했다. 내부 링크가 이 공간에 들어가는 것은 의도된 배치 표현이며, 속이 빈 외피의 상세 접촉/개구부 모델은 아니다. 실제 기구와 외피의 무충돌을 주장하지 않는다.

## 다음 제작 설계 관문

골반의 실제 축 오프셋과 모터 외형, 무릎 벨트·베어링·축, 발목 전달 장치의 모든 부품을 포함한 한쪽 뒷다리 CAD를 만든다. 계산한 발 위치/범위를 다시 확인하고, 전체 몸체와 조립했을 때 외피 틈·자가복구 도달 경로를 검사한다. 전류-토크·부하 응답·열·유격을 측정한 뒤 자유몸체 보행과 복구에 들어간다. 속도/응답 시간·총견적·실물 전이는 미확인이다.
