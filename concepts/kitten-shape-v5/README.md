# 새끼고양이 외형 V5

체크포인트 14 정정: 아래 GIM4305 선정은 **잠정 참고**로 변경했다. [Damiao 비교](../../hardware/kitten-damiao-review.json)를 포함해 모터 선정을 재검토한다. 이 화면의 형상·동작은 변경하지 않았다.

[3차원 화면](index.html). 이 V5는 외양을 우선하던 단계의 연구 모형이다. 이후 사용자가 움직임을 우선하고 모터를 정해 진행하도록 요청하여 **GIM4305-10 + Pupper V3용 GDS34**를 다음 배치 설계의 기준으로 선정했다([근거](../../hardware/kitten-actuator-baseline.json)). V5 화면에는 아직 반영하지 않았다. 네 발 걷기와 고양이다운 자세는 유지하며 사람처럼 두 발로 서기·걷기·팔 벌리기와 기존 19축 구성은 요구하지 않는다.

이 폴더는 새로 만든 외형 연구 모형이다. 이전 V4나 XL330의 축 배치·질량·모터 원통·물리 검증을 계승하지 않는다. 특정 고양이를 스캔한 모델이나 완성된 실사 고양이 모델도 아니다. 현재 표면은 털 없는 매끈한 형태이며 실제 털, 피부, 견갑골 움직임과 부드러운 조직의 변형은 재현하지 않았다. 자연스러움에 대한 사용자 승인은 아직 없다.

## 화면에서 볼 것

- 약 29cm의 코끝–엉덩이 길이(꼬리 제외), 기본 자세 등 높이 약 17cm. 특정 월령/품종의 실측이 아닌 **임시 비율안**이다. 바닥 눈금은 5cm다.
- 가만히 보기, 느린 네 발 걷기, 앉기, 몸 낮추기, 엎드려 쉬기, 기지개, 앞발 들어 보기. 각 자세 버튼은 바로 바뀌며 **자세 사이 전환 경로**를 검증한 것이 아니다.
- 외형/자세 뼈대, 앞/옆/위/입체 시점, 회전·확대, 시간과 재생 속도.
- 화면용 다리는 각 세 마디의 길이를 유지한다. 앞 50/55/23mm, 뒤 50/57/34mm. 마지막 발 덩어리의 방향은 화면 편의를 위해 수평으로 두므로 실제 발목·발가락 구조가 아니다. 외피는 그 뼈대를 따라 변형하는 그림용 표면이다.

보행은 중심에 몸을 두고 바닥을 이동시키는 경로 미리보기다. 한 주기 1.6초, 진행량 10cm, 디딤 비율 75%, 발 들기 16mm는 **화면용 설정**이며 실제 새끼고양이의 측정값이나 로봇의 성능이 아니다. 느린 걷기 표본에서 디디도록 지정한 발은 최소 세 개다. 접촉력 계산이나 균형 유지 성공을 의미하지 않는다.

## 아직 “된다”고 판단할 수 없는 것

식빵 자세, 몸을 둥글게 말기, 옆으로 구르기, 뒷발로 귀 긁기, 점프·착지·넘어짐 복구는 미구현이다. 앞발을 얼굴 쪽에 들 수 있는 화면만으로 발 회전과 혀 움직임을 포함한 세수가 가능하다고 보지 않는다.

외피 간섭·접힘·가동 범위, 내부 부품이 들어가는 공간, 배선·전달 장치, 실제 모터, 질량, 힘·열·지면 접촉·균형을 검사하지 않았다. 특히 낮은 자세와 앞발 들기의 큰 접힘 각도는 구동 구조를 정할 때 다시 검토해야 한다. 생물의 관절 가동 범위와도 대조하지 않았다. **현재 모형은 모터가 들어간다는 증거가 아니다.**

다음 단계에서는 선정 모터를 기준으로 필요한 자세 범위 → 축과 전달 장치 → 실제 모터 외형을 넣은 간섭 검사 → 질량과 힘 → 균형·보행을 검토한다. 이 단계에서 외형을 그대로 유지할 수 없으면 변경 이유와 손해를 사용자에게 보여준다.

## 참고한 근거

2026-10-24 확인. 본문의 치수·속도는 아래 연구의 측정값을 복사한 것이 아니다.

- [Miller & Van Der Meché, 1975](https://pubmed.ncbi.nlm.nih.gov/1164673/): 고양이 앞다리는 견갑골, 어깨, 팔꿈치, 손목과 발가락의 움직임이 결합한다. 여기서는 견갑골 움직임을 단순화했다.
- [Frigon 등, 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4044364/): 연구한 **성묘**의 네 발 걷기는 같은 쪽 뒷발 다음 앞발이 놓이는 순서였다. 발 순서만 참고했으며 성묘 데이터를 새끼고양이의 정확한 움직임으로 주장하지 않는다.
- [Basa 등, 2021](https://pubmed.ncbi.nlm.nih.gov/33225430/): 고양이 앞발의 회전은 기어오르기·몸단장에 관련된다. 이 때문에 단순히 팔을 드는 동작과 완전한 몸단장을 구분한다.

## 실제 실행한 검사

`validation.json`은 60표본/초의 7모드에서 화면용 다리 마디 길이, 발 끝점 도달 오차와 관절 중심의 높이를 기록한다. 도달 불가능한 목표를 넣어도 조용히 성공으로 처리하지 않는 경계 검사를 포함한다. 모터 범위·힘·충돌·실물 정밀도 검사가 아니다.

`browser_validation.json`은 실제 브라우저의 모드·시점·재생·표시 전환, 표면의 유한 좌표, 작은 화면의 넘침과 외부 요청을 검사한 결과다. 화면 외형의 전체 바닥 간섭 검증은 아니다.

저장소 루트에서 Node.js로 재생성한다. 브라우저 검사는 Playwright와 Edge가 필요하다.

```text
node concepts/kitten-shape-v5/build.cjs
node concepts/kitten-shape-v5/check_viewer.cjs outputs/kitten-v5
```

오프라인 실행용 `design-data.js`는 `design.json`에서 생성된다. Three.js와 MIT 라이선스는 이전 폴더 `../doro-model-v3/vendor/`를 공유한다. URDF나 MuJoCo 파일은 이번 외형 단계에서 만들지 않았다.

몸통과 다리 외형은 `coat.js`의 부드러운 합성 표면으로 연결한다. 이는 몸통과 다리 사이를 화면에서 매끈하게 만드는 방법이며 실제 외피 재료/두께/신축성 검사가 아니다. `vendor/MarchingCubes.js`는 Three.js r160의 [공식 원본](https://github.com/mrdoob/three.js/blob/r160/examples/jsm/objects/MarchingCubes.js)을 일반 스크립트로 불러오도록 감싼 파일이며 MIT 라이선스를 동봉했다.
