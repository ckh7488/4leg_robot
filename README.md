# 작은 보행 로봇 — 짧은 팔다리 BLDC 구조 탐색

> 신규 AI는 이 문서 → `docs/STATE.md` → `design.json` → 최신 `docs/audits/` 순서로 읽는다.

2026-10-24 새 방향: **큰 얼굴·짧은 팔다리로 네 발 보행, 두 발 보행, 넘어짐 복구**. BLDC 관절과 외부 전원 케이블의 당김 측정을 검토한다. **200만원은 예산 기준점이며 절대 상한이 아니다.** [새 구조안과 그림](concepts/short-limb-v1/README.md), [그림 중심 자료](concepts/short-limb-v1/concept.html)를 먼저 본다.

최신 검토는 [도로롱 전체 구조 V2](concepts/doro-layout-v2/index.html)다. 사용자가 크기와 가격을 당장 크게 제한하지 않도록 지시하여, 높이 약 69cm·질량 예산 약 15kg·19축의 전체 구조와 모터를 옮긴 전달 장치를 검토했다. 두 자세의 이상적 발 도달, 질량/힘 산술, 두 막대 발목의 첫 치수안을 계산했다. 실제 모터 전체 배치·제작 CAD·보행·자가복구는 미완료다. 아래 V1은 이전 작은 마디 비교안으로 보존한다.

현재는 외형·치수 범위·12/14관절 후보·단순 힘/질량 계산과 [한쪽 뒷다리 외형 검사](concepts/short-limb-v1/rear-leg/index.html)까지 진행했다. 지름 53mm의 모터 원통을 넣은 288표본에서 짧은 마디·깊은 접힘의 충돌을 찾았다. 전체 몸체의 배치·보행·실물은 미검증이다. 새 가정은 `concepts/short-limb-v1/design.json`에서 관리한다. 루트 `design.json`과 기존 모델/검사는 아래 XL330 기준 구현이며, 새 로봇의 성능 근거가 아니다.

## 이전 XL330 기준 구현

이전 목적은 직접 설계한 작은 12관절 로봇으로 보행·균형·RL sim-to-real을 익히는 것이었다. **아래 100만원·700g·XL330 조건은 이전 구현의 기록이며 새 방향에는 적용하지 않는다.** 라이다·적재·2시간 운용은 당시 요구사항이 아니었다. 반응성은 최고 RPM으로 단정하지 않고 부하를 건 명령-동작 지연으로 평가한다.

현재 판정: 모델 복구·정지 자세 검사는 통과했다. 반응성은 빠르기와 하중 정확도를 분리해 판정하며, 현재 설계 게인(P 400)은 단축 모델에서 빠르기 목표 미달이다. 전원(5V 대전류)·부품표는 미설계다. 최신 판단과 다음 작업은 `docs/STATE.md`에 기록한다.

## 이전 구현의 결정

- 모터: ROBOTIS XL330-M288-T 12개. 예비 2개를 포함한 모터 예산 369,600원(VAT 포함 공식가 기준).
- 전원: 모터에 정전압 5V. 2S 배터리를 모터에 직결하지 않는다. 참고 Microduck의 6.5–8.2V 설정은 복사하지 않는다.
- 전체 무게 목표 700g(초기 600g에서 변경, 체크포인트 3). 현재 CAD/할당 질량은 약 671g이며 나사·배선을 포함한 실측값이 아니다.
- 다리당 HAA/HFE/KFE 3축. 기준축·순서·부호는 기구/시뮬/실기 인터페이스에서 공통으로 관리한다.
- 반응성은 빠르기(최초동작·도달 시간)와 하중 정확도(하중당 처짐, °/N·m)를 따로 본다. 비례 제어만 쓰는 위치 제어는 하중만큼 처진 채 멈추므로, 하중 상태의 명령 각도 ±0.2° 정착은 판정 기준이 아니라 진단값이다.
- 모터 데이터·마찰·지연의 출발점은 BAM. 모델의 존재가 우리 장치의 sim-to-real 성공을 보장하지 않는다.
- Bambu 출력은 실제 프린터 기종 확인 전까지 180×180mm 베드, 0.4mm 노즐 기준. 프린터·PC 구매비 제외, 재료비 포함.

## 폴더 안내

| 경로 | 내용 |
|---|---|
| `concepts/short-limb-v1/` | 현재 새 구조 탐색; 별도 design.json·그림·계산 |
| `design.json` | 이전 XL330 구현의 설계 기준값; 해당 모델의 원본 |
| `cad/` | FreeCAD 원본과 STEP 조립체, 부품 목록 |
| `print/` | 부품별 STL/3MF, 출력 방향과 수량 |
| `models/` | MuJoCo/URDF 및 구동계 설정 |
| `scripts/` | 생성·검증·보고서 재현 코드 |
| `control/` | 명령/관측 계약과 구동계 구현 |
| `hardware/` | 전원·BOM·배선 미결 항목 (아직 설계 전) |
| `reports/` | 실제 실행한 검사 결과; 통과 범위를 그대로 기재 |
| `docs/STATE.md` | 현재 단계와 다음 작업 |
| `docs/audits/` | 체크포인트 뒤 재검토 기록 |

## 상태 표기의 의미

`verified` = 명시된 환경에서 실제 실행·계산했다. `design_target` = 목표값. `reference` = 타 프로젝트 데이터. `unmeasured` = 실물 측정 전. `blocked` = 해당 단계로 진행할 수 없는 미해결 항목.

**정지 자세 시뮬레이션 통과를 보행 성공으로, CAD 유효성을 체결/강도 검증으로, 명령 주기를 실제 반응 시간으로 바꾸어 쓰지 않는다.**

요청에 따라 체크포인트마다 커밋/푸시하고, 커밋된 파일을 다시 읽어 반증할 항목을 찾는다. 이 저장소는 제작 전 검토 가능한 설계 기록이며 현재 실물 보행·열·내구·RL 전이 성공을 주장하지 않는다.
