# 요구사항과 검증 기준

| ID | 요구 | 판정 방식 |
|---|---|---|
| R1 | 총예산 100만원 이하 | BOM + 배송/재출력/예비부품 포함. 실구매 견적은 별도 |
| R2 | 작고 가벼운 4족 | 초기 질량 목표 0.6kg; CAD/부품 실제 중량으로 갱신 |
| R3 | 반응성 | 부하 시험에서 최초동작 지연·작은 각도 정착시간·지터 측정 |
| R4 | MuJoCo/Isaac 연동 | 공통 구동계/관절 계약; 각 엔진에서 실제 실행 여부 구분 |
| R5 | Bambu 출력 | 180mm 베드에 개별 부품 배치 가능; 0.4mm 노즐 적합성/쿠폰 실측 |
| R6 | 감사 가능성 | 출처·생성 코드·원시 결과·한계·커밋 기록 |

반응성의 초기 수용 목표는 최초동작 p95 ≤40ms, 부하 10도 명령의 정착 p95 ≤150ms다. 둘 다 설계 목표이며 실측 전 보장하지 않는다. 기어 유격, 온도, 공급전압, 부하와 측정 정의를 함께 저장한다. 어려운 sim-to-real 자체가 좋은 성능의 근거는 아니다. 예측하고 측정할 수 있는 구동계를 만드는 것이 목적이다.
