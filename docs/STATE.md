## 현재 판정

반응성 모델 목표 미달. 현재 단축 모델에서 움직임 시작은 21~29ms이지만 명령 각도 ±0.2° 정착/150ms 수치 기준은 6조건 모두 미충족이다. ±0.2°와 최소 관찰 유지 100ms는 이번에 design.json에 명시한 선별 기준이다. 부하별 위치 오차가 남으며 관찰 시간 내 목표 범위에 정착하지 않았다. 이 결과는 실제 모터 성능이나 p95 측정값이 아니다.

전체 CAD 검사는 reports/archive/cp003/checkpoint-validation.json 및 커밋 f6dea2c를 기준으로 한다. 최신 실행 범위/입력/산출물 해시는 reports/checkpoint-validation.json을 읽는다. 계산 명령 정상 종료와 반응성 목표 충족은 별도 필드다.
