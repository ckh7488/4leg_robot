# 현재 상태

2026-10-24. 체크포인트 3 검증 완료: 중단된 미커밋 CAD·시뮬레이션 작업 복구 및 재현 검사.

작은 자작 12관절 4족, XL330-M288-T 12개, 모터 정전압 5V, 총예산 100만원 상한을 유지한다. 기존 로컬 설계의 질량 목표는 700g이며 초기 600g 목표를 만족한 것으로 취급하지 않는다.

## 이번 단계

- 기존 경량화 CAD, MuJoCo/URDF, BAM 구동계, STL/3MF를 저장소에 복구한다.
- CAD와 시뮬레이션 Python을 분리하고 고정 의존성 및 단일 검사 명령을 제공한다.
- CAD 간섭/다리 동작 검사에 실패 종료 코드를 추가하고, 관절 순서·부호·한계·질량·관성을 검사한다.
- 실제 실행 결과는 reports/checkpoint-validation.json 및 개별 보고서를 기준으로 한다.

실행 결과: 13개 명령 통과. 기준 자세 간섭 0건, 각 다리 27자세(총 108자세) 간섭 0건. 독립 URDF/MuJoCo 33자세 최대 발 위치 차이 5.01e-17m 미만. 12관절 모델 670.771g, 출력물 솔리드 계산 195.77g, 5초 정지 자세 통과. 실제 보행/실측 결과가 아니다.

## 다음 순서

1. 부하 응답 평가에서 명령 각도와 실제 정착 위치를 구분하고 위치 오차·반응성 목표를 함께 판정한다.
2. 실제 다리 하중·지연 조건에서 구동계 여유를 비교한다.
3. 여러 다리 동시 움직임, 나사·공구·배선 간섭을 보강한다.
4. 기본 보행/외란 시뮬레이션, 한 다리 조립·부하·반응성 실측, RL로 이어간다.

## 남은 문제

5V 개체별 구동계 모델/연속 토크/발열/전압 강하 실측 없음. 여러 다리 동시 이동·연속 경로·나사머리·공구·배선·강도 미검증. 실제 프린터/노즐/재료와 구매 SKU·재고·납기 미확정. Isaac 실행, 보행, RL 및 sim-to-real 미실행. 공식몰 가격/납기는 초기 참고 기록이며 발주 전 재확인한다.
