## 구매·전체 출력 전에 반드시 확인

1. 공식몰 준비기간 40일(휴일 제외) 표기; 실제 재고/납기 미확인.
2. 제조사 연속 정격 토크 미제공. 0.52Nm는 5V stall 값이다.
3. BAM 모델은 타 개체/측정조건의 모델. 5V, 실제 PWM slope/게인에서 다시 비교해야 한다.
4. Bambu Studio는 슬라이서. 실제 프린터·노즐·재료·출력 오차는 아직 미확인.
5. 케이블 굽힘, 나사머리/공구 접근, 한 다리 조립 적합성, 발열은 실물 게이트다.
