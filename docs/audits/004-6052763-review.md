# 체크포인트 4 커밋 후 재검토

대상: 6052763. 커밋된 design.json, BAM 래퍼, 응답 지표/실행/회귀검사 파일을 git show로 꺼내 _runs 아래의 별도 폴더에 저장했다. 해당 폴더의 파일로 재실행했다.

## 재실행 증거

- 응답 지표 회귀검사 6개 통과.
- 양방향 10°/부하 0·0.05·0.1Nm의 6조건을 다시 계산. 작업 폴더 보고서와 독립 추출본 보고서가 전체 일치했다.
- --require-targets는 예상한 종료 코드 1을 반환했다. 6조건 모두 명령 ±0.2° 정착/150ms 선별 기준 미달이며 statistical_p95_verified=false를 유지했다.
- 커밋 직전 최신 검증 보고서의 입력/산출물 SHA-256과 Git 스테이징 내용을 모두 비교해 불일치 0건을 확인했다.
- 별도 CAD 복사본의 의도적 간섭 시험은 기준 자세 검사 종료 1, 다리 동작 검사 종료 1 및 14개 불합격 자세를 기록했다. 원본 CAD에는 간섭을 추가하지 않았다. 재현 명령은 docs/VALIDATION.md에 있다.

## 판단

이전 감사의 명령/실제 위치 혼동, 고정 기본 게인, 표본 시간 오프셋, 단방향/짧은 관찰 범위는 수정되었다. 계산 실행 성공과 반응성 목표 충족을 분리했으며, 현재 설계가 반응성 목표를 달성했다고 판정하지 않는다. ±0.2°/100ms 관찰 유지는 이번에 명시한 모델 선별 기준이다.

실제 5V 개체 보정 전 BAM 예측으로 모터의 실물 성능을 확정할 수 없다. 단축 중력 시험은 조립된 다리도 아니므로 다음은 실제 다리 하중/지연/마찰/제어 조건 비교이다. 명령 누락 시 정지 구현, 동시 다리/연속 경로/체결/배선, 실물 발열, 보행·Isaac·RL 검증도 남아 있다.

출력 3MF는 검사 과정에서 재생성되었으며 기존 압축 패키지의 생성 시각도 바뀐다. STL/3MF 형상 검사는 통과했으나 프린터별 슬라이싱을 실행한 것은 아니다.
