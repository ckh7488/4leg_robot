# 도로롱 전체 구조 V2 검토

2026-10-24. 구현 `644c30e`, 표현/적용 범위 수정 `1082f9e`. 커밋된 전체 배치 계산, 발목 닫힌 연결식, 독립 거리 검사 코드를 다시 읽고 커밋 추출본에서 재생성했다. 사용자가 크기/가격보다 실제 기구 구조를 우선하도록 한 최신 지시를 적용했다.

## 발견과 처리

1. **중립 발목 토크만 표시하면 부하 능력을 과대평가할 수 있었다.** 앞뒤 8N·m/좌우 6N·m 예시에서 중립 모터 토크는 약 7.33/1.46N·m지만, 30각도 전체의 최대는 10.29N·m다. 참고 AK70-9의 공시 정격 8.5N·m보다 크다. `1082f9e`에서 보고서와 README에 최대값과 정격 초과 표본을 명시했다. 더 큰 모터·추가 감속·허용 자세/지속 시간 검토가 필요하며 모터를 선정하지 않았다. 최대 토크 29.2N·m를 연속 정격으로 대신 쓰지 않는다.
2. **기하적으로 움직이는 범위와 부품 간격을 분리했다.** 발목 회전 팔 22/30/40/50mm의 30표본 중 막대 길이 조건을 만족한 수는 10/18/26/30개다. 처음 50mm 회전 팔/하우징 중심 ±55mm에서는 막대-모터 간격 하한이 양수인 조건이 24개였다. 회전 팔 설치 평면 ±100mm를 유지하고 하우징을 ±40mm로 옮기면 30개 모두 양수다. 두 배치 비교를 결과 JSON에 남겼다.
3. 위 수정은 공짜 공간 확보가 아니다. 모터 원통 바깥면에서 회전 팔 평면까지 약 35.5mm의 축 연장, 회전 팔 설치 평면 사이 200mm가 필요하다. 별도 지지 베어링·종아리 프레임·외피 공간을 설계해야 한다. 막대 좌굴과 연결부 허용 하중도 미검증이다. 회전 팔·축·지지 구조 등 빠진 부품까지 간섭이 없다고 주장하지 않았다.
4. 구현 도중 앞팔의 같은 운동 평면을 큰 좌우 각도(약 ±162°)로 표현하여 범위를 벗어나는 문제가 있었다. 평면의 작은 좌우 각도 표현을 선택하고 앞뒤 축으로 위쪽 도달을 표현하도록 고쳤다. 관절 제한을 넓혀서 통과시키지 않았다. 수정 후 끝점 역/순기구학과 링크 길이를 함께 확인했다.
5. 전체 몸체 모델은 골반 축이 한 점에서 만나는 이상화이며, 뒷다리의 기준 자세는 시상면이다. 실제 19개 모터와 베어링 오프셋을 조립한 CAD가 아니다. 그림 XML도 정적 도형만 포함한다. 제어·시간 전진·접촉 동역학·보행 시험을 실행했다고 쓰지 않았다.
6. 질량 14.992kg은 참고 모터 9.342kg + 기타 배분 5.65kg이다. 머리 650g을 포함한 배분은 CAD/실측값이 아니다. 질량점 위치 또한 가정이다. 머리 폭 46cm를 로봇 최대 폭으로 바꾸어 쓰지 않았다. 24V 머리 모터 참고품과 48V 몸체 전원의 차이도 표시했다.
7. 복구 계산은 외피 접촉 자세의 어깨-바닥 거리와 장애물 없는 최대 도달 반경 비교다. 팔 경로·실제 팔다리 접촉·마찰·밀어 올리는 힘을 확인하지 않았다. 두 발 지지 영역 안에 무게중심 투영이 들어오는 것도 필요 조건이며 보행이나 안정성 판정이 아니다.
8. 루트 안내와 요구사항에 남은 V1 우선 링크를 V2로 수정했다. 기존 XL330의 100만원/700g/5V 기준과 작은 마디 V1 계산은 별도 기록으로 남겼다.

## 실제 실행 결과

- 두 발/네 발 기준 자세의 8개 팔다리에서 지정 끝점과 순기구학의 최대 오차 6.21e-17m. 링크 길이, 기준 뒷발 방향 보정, 가정한 관절 범위 검사 통과.
- 네 발을 지정 지점에 둔 몸통 각도·높이 16조합 중 8개가 도달/가정 범위를 함께 만족했다. 이 수를 전환 동작 성공률로 해석하지 않는다.
- 전체 높이 0.692m, 머리 폭 0.46m, 두 발 기준 몸통 공간 아래 높이 0.162m. 무게중심 높이 예산은 두 발 0.2915m/네 발 0.2213m. 질량점 합계와 별도 부품별 예산 합계 일치.
- 한 발 수직 힘 147.0715N만 대입한 무릎 기여분은 약 70°에서 11.4726N·m, 약 111°에서 16.6442N·m. 전체 균형·다리 무게·관성·수평 힘은 생략했다.
- 발목은 회전 팔 4종 × 30각도 = 120표본. 고정 막대 길이 잔차, 해석 미분과 ±1e-6rad 중앙 차분을 비교했다. 미분 최대 차이 6.71e-7, 허용 1e-5 이내. 모터 토크에서 막대 축력을 구한 뒤 실제 작용점의 외적으로 관절 모멘트를 복원해 가상 일 식의 부호/전치를 독립 확인했다.
- 선택한 50mm 회전 팔/하우징 ±40mm의 30표본에서 조건수 최대 2.288, 보수적 막대-모터 간격 하한 최소 4.09mm. 표본 사이와 다른 부품의 무충돌은 미검증이다. 동일한 힘 예시의 최대 모터 토크 10.29N·m, 최대 막대 축력 크기 약 308N.
- 선택 30표본과 두 몸체 기준 자세의 실제 발목 각도 2개를 별도로 검사했다. MuJoCo 3.3.7 `mj_geomDistance`의 원통/캡슐 최소 간격 4.4673mm. 모두 보수적 하한보다 크며 최대 차이는 0.37791mm였다. 로컬 거리식과 다른 구현으로 확인한 범위는 막대-모터 쌍뿐이다.
- `644c30e`와 최종 수정 `1082f9e`의 추출본에서 각각 `report.json`, `index.html`, `verification.json`, 정적 그림 XML 4개의 재생성 바이트 일치. 입력 JSON을 CRLF로 바꿔도 같은 7파일 일치. PNG는 로컬 렌더/열람했으며 환경 간 바이트 재현은 주장하지 않는다.
- Edge에서 자세 버튼 3개, 화면에 사용하는 이미지 3개 및 변경되는 자세 이미지, 수치 카드 4개, 발목 후보 4행, 로컬 링크 4개를 확인했다. 자바스크립트 오류 0건. 390px 화면에서 가로 넘침 없음. 전체 배치와 발목 설명 영역을 스크린샷으로 열어 확인했다. 정격 초과 설명 추가 후 UI 검사를 다시 실행했다.
- 기존 XL330 모델과 제어 코드를 변경하지 않았고 기존 검사를 V2 증거로 재사용하지 않았다.

## 근거와 남은 관문

공식 논문의 실제 캐릭터 이족 로봇과 벨트 구동 보행 로봇, 제조사의 모터 사양을 확인해 `design.json`에 출처와 날짜를 기록했다. 타 로봇의 실물을 이 형상의 보행/전환/복구 실증으로 인용하지 않는다.

다음은 뒷다리 한쪽의 실제 모터·골반 축 오프셋·벨트·풀리·축·베어링·발목 연결부 전체를 포함하는 CAD다. 전체 외피/네 다리/목 간섭, 복구 팔 경로와 힘, 출력축 유격·연속 부하·열·부하 응답 측정, 자유몸체 보행/복구가 남아 있다. 현재 결과로 구매나 제작을 확정하지 않았다.
