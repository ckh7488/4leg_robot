# 전신 관절 모델 V3 검토

2026-10-24. 구현 `7f2b6b6`, 검토 수정 `fd4e7f3`의 입력·관절 생성·동작·검사 코드를 다시 읽었다. 수정 커밋 추출본에서 재생성 및 오류 주입 검사를 실행했다. [재현 파일 해시](012-articulated-model-reproduction.json).

## 범위

사용자의 요청은 관절과 움직임을 볼 수 있는 전신 로봇 모델이다. 19축·20링크의 연결된 모델, 캐릭터 표면, 모터 공간, 오프라인 3차원 화면과 MuJoCo/URDF를 제공한다. 7개 모드 중 서기/네 발 자세는 정적 자세, 나머지는 몸통 경로를 지정한 관절 미리보기다. 물리적 균형이나 제작 설계 완료로 표시하지 않는다.

## 발견과 수정

1. 어깨 벌림 축과 앞뒤 축 사이의 간격을 무시한 앞팔 계산은 지정한 손 위치에서 벗어났다. 벌림에 따라 바깥쪽 오프셋도 회전하도록 역기구학을 고쳤다. 팔꿈치의 양의 접힘은 음의 Y축이며 URDF·MuJoCo·화면에 일치한다.
2. 팔을 모을 때 상완이 몸통/골반 모터를 통과했다. 어깨를 몸통보다 140mm 앞으로 옮겼다. 팔꿈치 구동 모터 공간을 상완의 앞쪽으로 옮기고 몸통 고정 공간을 좁혔다. 이 수정은 실제 지지대/외피의 제작 적합성 검증이 아니다.
3. 몸통과 함께 손 목표를 돌린 네 발 전환은 앞발 바닥 침범과 팔/뒷다리 겹침을 만들었다. 세계 좌표계에서 앞발을 바깥으로 돌아 내려놓는 경로로 수정했다. 최종 583표본에서 설정된 충돌 도형의 1mm 초과 겹침·바닥 침범은 없다.
4. 자동 접촉 검사는 같은 링크/이웃 링크를 제외하므로 모터 19개의 모든 쌍을 별도로 조회했다. 오류 주입 중 MuJoCo 3.3.7이 완전히 같은 위치의 원통 두 개에 거리 0을 반환하는 경우를 발견했다. 원통에 내접하는 구의 겹침으로 보완했다. 보완값은 확실한 침범 하한이며 복잡한 실제 하우징의 정확한 간격이 아니다.
5. 첫 화면 프레임의 시간 차가 음수가 되면 동작 프레임을 찾지 못했다. 시간 차의 하한을 0으로 두었다. 수동 관절 조작 중 무게중심은 현재 링크 위치로 다시 계산하고 이전 손발 목표는 숨겼다. 좁은 화면에서는 카메라 거리를 화면 비율에 맞춘다.
6. Windows 추출본의 URDF/자바스크립트/구 메시 줄바꿈 변환으로 바이트 재현 검사가 실패했다. 내용은 같았으며 V3 파일에 LF를 지정했다. 수정 커밋 추출본은 아래 9개 생성 파일의 바이트가 일치한다.

- 동일 표본에서 자동 충돌 도형 및 모든 모터 쌍의 1mm 초과 겹침 0건, 바닥 침범 0건. 외피/배선/지지대와 표본 사이 연속 경로는 제외한다.
- 독립 URDF 순기구학과 MuJoCo를 전체 동작 및 무작위 32자세에서 비교: 링크 위치 차이 최대 2.0063e-16m, 회전 행렬 차이 7.7716e-16. 19개 관절/입력, 20개 링크, 질량 할당 16.272kg, 양의 관성 확인.

## 남은 설계

흰 외피와 분홍 머리카락은 중공 두께/개구부가 없는 표면이며 충돌 검사에서 제외했다. 장착 베어링·축·체결부, 원격 구동 벨트, 발목의 두 모터/두 막대 실제 전달 관계, 케이블/센서·전원 설계를 완성해야 한다. ±30N·m와 20rad/s는 임시 출력축 한계이며 구매 모터의 보장 성능이 아니다. 질량·관성·마찰·감쇠 역시 가정이다.

목은 앞뒤 1축이고 허리는 고정이다. 실제 한 발 지지·전진 보행·춤·두 발/네 발 전환·자가복구, 부하 반응·열·내구·실물 전이와 Isaac은 미검증이다. 3차원 미리보기 성공을 이 항목들의 성공으로 확대하지 않는다.
