# 새끼고양이 외형 V5 검토

2026-10-24. `c79bf9f`의 요구사항, 자세 계산, 표면 생성과 검증 범위를 다시 읽었다. 커밋에서 추출한 입력으로 생성 결과를 재현했다. [재현 기록](014-kitten-exterior-reproduction.json).

## 범위 수정

사용자는 사람형 두 발 서기/걷기와 팔 벌리기보다 실제 새끼고양이에 가까운 외양·크기·네 발 걷기·고양이다운 자세를 원한다. 마지막 지시로 **외양의 3차원 표시가 당장의 우선순위**이고, 실제 구조와 모터 선정은 뒤로 미뤘다. 기존 19축·모터·질량을 V5에 복사하지 않았다. AGENTS/README/STATE의 현 요구를 갱신하고 V4에는 최신 화면 링크와 이전 비교안 표시를 추가했다.

새 모형은 약 29cm 길이·17cm 등 높이의 임시 비율이다. 특정 새끼고양이의 실측/스캔이 아니다. 앞·뒤 다리와 몸통을 매끈한 표면으로 합성하고 작은 발·고양이 머리·귀·꼬리를 붙였다. 현재 모형은 털 없는 조형 형태이며 실사 수준이나 자연스러움을 사용자가 승인한 것으로 보지 않는다.

## 발견과 수정

- 초기 낮은 자세에서 팔꿈치 중심이 바닥 아래에 놓였다. 자세 높이와 링크 길이/경로를 수정하고 관절 중심 높이 검사를 추가했다.
- 다리를 줄인 뒤 걷기 목표가 약 1.33mm 도달 범위를 넘었다. 화면용 보폭을 줄이고 실패를 검사에서 계속 거부한다. 실제 모터의 허용 범위를 정한 것은 아니다.
- 앞발이 어깨 위로 갈 때 벌림각이 뒤집히던 계산을 수정했다. 목표가 몸 중심 평면을 가로지르는 상태와 다리 길이를 유지한다.
- 분리된 표면의 열린 끝·관절 덩어리와 몸통 법선 방향을 화면에서 확인했다. 최종 몸통/다리는 연속 합성 표면으로 대체했다. 이 합성은 실제 피부/외피의 물리적 연결을 입증하지 않는다.
- 변형 전의 경계 상자를 재사용하면 낮은 자세에도 높은 꼬리의 범위가 남았다. 브라우저 검사는 현재 활성 꼭짓점으로 표시 범위를 계산하도록 수정했다.
- 멈춘 화면을 계속 그리던 동작을 고쳐 화면 변경 시에만 다시 그린다. 재생 시간은 실제 경과 시간을 따른다. 모든 기기의 재생 성능을 보장하지 않는다.

## 실제 확인

- 7모드, 60표본/초, 총 2,083표본. 앞/뒤 세 마디 길이 유지, 발 끝점 오차 최대 5.64e-17m, 마디 길이 차이 최대 2.78e-17m. 이는 계산 내부 일치이며 실물 정밀도가 아니다.
- 검사한 관절 중심은 바닥 위다. 도달 불가능한 가까운/먼 목표를 성공으로 처리하지 않는 경계 검사를 통과했다.
- 걷기에서 예정된 디딤 발 최소 3개, 디딤 구간의 발과 이동 바닥 사이 표본당 수평 미끄럼 차이 최대 7.18e-17m. 접촉력/균형 검증이 아니다.
- Edge 1280/390/320px. 7모드·35개 표면 표본의 유한 좌표, 모드/표시/시점/시간/재생 속도, 가로 넘침, 링크 존재 검사 통과. 자바스크립트 오류와 외부 요청 0건. 기본/앉기/엎드리기/앞발 들기 화면을 직접 확인했다.
- 표시 범위 표본에서 엎드린 자세의 합성 외피는 지면 아래 약 0.77mm에 이른다. 바닥 높이를 강제로 잘라 성공으로 숨기지 않았다. 전체 외피 간섭·변형 검사는 아직 없으며 제작 외피로 사용할 수 없다.
- 커밋 추출본에서 `build.cjs`를 다시 실행해 `design-data.js`와 `validation.json`이 커밋 바이트와 같음을 확인했다.

## 남은 판단

외양은 첫 검토용 초안이다. 실제 털/피부, 귀와 견갑골의 개별 움직임, 생물의 가동 범위, 식빵/몸 말기/구르기/귀 긁기/점프/복구, 자세 사이의 전환은 미완료다. 발 덩어리는 그림 편의를 위해 수평으로 두며 실제 발목 구조가 아니다. 내부 부품과 전달 기구의 공간, 질량, 토크·열·접촉·균형·실물 걷기를 이번 성공으로 간주하지 않는다. 다음은 사용자 외양 피드백 반영이며 아직 모터 선정으로 넘어가지 않는다.
