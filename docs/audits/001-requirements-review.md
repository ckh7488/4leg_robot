# 체크포인트 1 재검토 계획

입력: README.md, design.json, REQUIREMENTS.md. 생성 시점에 계산 결과나 하드웨어 실측은 아직 없다.

검토 포인트:
- 100만원이 부품비만인지 전체 지출인지: 예비 모터/배송/재출력 포함 상한으로 명시.
- 출력비 절감으로 모터값까지 줄어드는 착각: 부품별 BOM 분리 예정.
- XL330의 stall 수치를 연속 토크로 사용하지 않는지: continuous_torque_nm=null.
- 참고 로봇의 과전압/게인/PWM slew를 그대로 사용하는지: 5V 원칙, 실제 설정 캘리브레이션 필요.
- 500Hz 명령 갱신을 2ms 기계 반응으로 오해하지 않는지: 지연/정착시간 별도 수용 기준.

다음 감사는 CAD 조립/운동 범위/나사 체결과 출력 준비 상태를 직접 검사한다.
