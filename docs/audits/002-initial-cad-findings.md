# 초기 CAD 체크포인트 감사

검사 대상: scripts/build_cad.py 및 reports/cad-build.json. 115개 조립 객체, 21종 출력 부품. 이 단계는 제작 승인 아님.

실행 결과: 형상 유효성/개별 180mm 베드 수용/기준 자세 발바닥 높이 계산 통과.

중요 발견:
1. 출력부품을 완전 솔리드로 계산하면 356.4g. 당초 구조 예산 160g를 초과하므로 질량 목표를 만족했다고 주장할 수 없다. 구조 경량화 후 질량 예산 재산정 필요.
2. HAA 브리지와 HFE C 캐리어의 별도 체결 위치에 실물 조립 근거가 부족하다. 두 형상을 한 부품으로 합쳐 불필요한 접합부를 제거할 예정.
3. 발패드와 브리지의 체결부 간섭/고정 나사 경로를 별도 확인해야 한다.
4. 모든 형상에 대해 양의 겹침 체적을 검사하고 의도된 접촉과 실제 간섭을 구분할 것.

위 문제를 숨기지 않기 위해 이 초기 상태를 커밋하고 다음 변경에서 해결한다.
