# 짧은 팔다리 BLDC 개념 설계 검토

2026-10-24. 검토 대상: 개념 설계 `33dda9f`와 재현 수정 `5d58d11`. 사용자 참고 이미지, 짧은 팔다리, 두 발 **보행**, 자가복구, 외부 전원/당김 측정 및 완화된 예산 기준이 문서와 새 가정 원본에 반영됐는지 확인했다.

## 발견과 처리

1. **커밋 추출본 재생성이 처음에는 불일치했다.** Windows 작업 파일의 CRLF 바이트를 해시한 뒤 Git이 LF로 정규화하여 입력 해시와 생성물이 바뀌었다. `screen_design.py`에서 입력 텍스트의 줄바꿈을 LF로 정규화해 해시하고, 출력도 LF로 고정했다. 수정 커밋에서 추출한 소스로 HTML/JSON을 재생성했을 때 커밋된 바이트와 일치했다. 입력만 CRLF로 바꾼 재시험에서도 동일했다.
2. 참고 그림의 얼굴이 두 자세 모두 앞을 보는 것은 고정 머리로 보장되지 않는다. 머리 기울기 1축을 따로 기록하고 질량 가정에 60g을 포함했다. 따라서 보행 관절 12/14개와 전체 축 13/15개를 구분한다. 실제 머리 기구는 미설계다.
3. 두 발 보행의 한 발 지지 하중을 네 발 지지처럼 나누면 토크를 과소평가한다. 지지 발 수 4/2/1을 명시하고, 가속·충격·수평 힘·다리 무게를 제외한 수직 지면 반력 기여분이라는 범위를 표시했다. 다리 전체 길이를 수평 지레 길이로 취급하지 않는다.
4. 14관절안의 추가 발목은 앞뒤 기울기 축이다. 좌우 발목 제어까지 생기는 것으로 쓰지 않았다. 두 자세에서의 실제 관절 축·발 접촉·한 발 균형은 미검증으로 남긴다.
5. arXiv:2407.02282 원문은 시뮬레이션 결과다. 실제 보행 성공 근거로 사용하지 않고, 별도의 실제 두 발 동작 연구와 구분했다. 생성 그림도 기구 배치나 보행 실증으로 취급하지 않는다.
6. 이전 100만원/700g/XL330 요구사항과 새 방향이 섞이지 않도록 README, STATE, REQUIREMENTS, AGENTS에 적용 범위를 적었다. 루트 설계값과 기존 모델/제어 코드는 변경하지 않았다.

## 실제 확인한 범위

- 표준 Python으로 정적 가정 18조건, 모듈 질량 기반 예산 4조건을 생성했다. 4kg/수평 3cm에서 네 발 0.2943, 두 발 0.5886, 한 발 1.1772 N·m의 단순 기여분을 확인했다. 이 값은 모터 정격이나 전체 역동역학 결과가 아니다.
- 12/14개의 질량 참고 모듈에 기타 가정 1.2kg을 더한 총질량은 각각 AK40 3.48/3.86kg, EduLite 4.104/4.588kg이다. 기타 가정은 실측·CAD 질량이 아니다. 모터는 선정하지 않았다.
- 수정 커밋 추출본의 `concept.html`, `screening.json` 재생성 바이트 일치. 줄바꿈 정규화 후 입력 해시 일치 및 CRLF 입력 재현 확인.
- Edge에서 화면 표시, 질량·지레 길이·지지 발 수 변경, 이미지 로딩, 지역 참조 링크 4개를 확인했다. 자바스크립트 오류 0건. 390px 화면에서 문서 가로 넘침 없음. 계산 표를 이미지로 열어 글자 겹침을 확인했다.
- `git diff --check` 통과. 기존 모델/제어를 수정하지 않아 기존 보행 관련 검사를 재실행하지 않았으며 새 구조에 그 결과를 인용하지 않는다.

## 미완료와 다음 관문

실제 모터 배치, 관절 축/가동 범위, 몸통·팔다리 충돌, 발 도달 범위, 지면 접촉, 질량/관성, 자유몸체 시뮬레이션, 보행, 넘어짐 복구, 연속 발열, 회생 전력, 실물 전이, 전체 견적은 미검증이다. 다음 단계는 두 자세와 넘어진 자세에서 실제 모터 외형을 포함한 기구 배치와 도달 검사다. 개념 산술 검사를 제작 승인으로 취급하지 않는다.
