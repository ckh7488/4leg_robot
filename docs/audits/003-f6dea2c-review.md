# 체크포인트 3 커밋 후 재검토

대상: f6dea2c. git show로 커밋된 응답 스크립트, 구동계, 실행기와 보고서를 다시 읽었다. 커밋된 입력/핵심 산출물 21개와 실행 보고서 SHA-256도 대조하여 불일치 0건을 확인했다.

확인: 독립 Python 3.12 환경에서 13개 명령 정상 실행. CAD 기준 자세/각 다리 27자세, 33자세 URDF/MuJoCo 계약, 5초 정지 자세, STL/3MF 검사 통과. 이는 보행/실물/Isaac 검증이 아니다.

발견과 조치:

1. 응답의 settle_to_final_band_ms는 최종 실제 위치를 기준으로 한다. 기본 부하 0.1Nm 보고서는 위치 오차 5.7134°인데도 594ms 정착을 표시한다. 명령 각도 허용 범위 정착과 분리해야 한다.
2. 응답 스크립트는 --kp 기본값 400으로 design.json 값을 덮어쓴다. 기본 실행이 설계 원본을 그대로 쓰도록 수정한다.
3. 1ms 적분 후 저장한 표본에 인덱스 i를 ms로 사용하므로 최초 반응/정착 시간이 1ms 작다. 실제 시뮬 시간과 명령 입력 시간을 사용한다.
4. +10°만 검사하고 관찰 구간도 1초뿐이다. -10°와 +10°, 부하 0/0.05/0.1Nm, 충분한 초기 안정화 및 명시된 관찰 구간으로 확장한다.
5. 참고 모델은 실제 5V 개체 보정이 없다. 수치 기준 충족 여부는 단일 결정론적 예측 선별이며 p95 검증으로 바꾸어 쓰지 않는다.

위 1~4를 다음 코드 체크포인트에서 수정하고 회귀검사로 고정한다. 아직 실제 모터 게인이나 기구를 바꾸지 않는다. 여러 다리 동시 이동/체결/배선/실물 열은 계속 미검증이다.
