# PR #1 최종 검토

검토 기준: main 4e4122e 대비 PR 전체 변경과 보완 커밋 c61f72c. 사용자 요청에 따라 코드·설계값·재현 스크립트·보고서·문서 및 GitHub 검토 의견을 확인했다. 하드웨어 동작 승인은 포함하지 않는다.

## 범위와 판단

- 응답 지표: 명령 시점, 양방향 부하 시험, 최종 위치 추정의 유효성, 최소 도달량, 명령 오차 및 속도 수용 필드를 확인했다. 속도와 정확도의 분리는 채택하되 속도 통과만으로 전체 성능을 승인하지 않는다.
- 게인 비교: 설계값을 변경하지 않고 비교하며, 무효 지표를 null로 보존한다. 현재 설계 게인이 고정 비교 목록에 없는 경우도 포함한다.
- 서 있기 보고서: 현재 모델의 1ms 간격과 12개 단축 관절 순서에서 초기 100ms/마지막 1초 토크 집계가 일치한다. 스톨 대비 비율은 연속 토크나 보행 성능 판정이 아니다.
- 설계/문서: 정확도 불가능성 단정을 정정했고, 전원 17.64A는 공시 스톨 전류의 참고 합계로 한정했다. 기존 형상·구동 게인·하드웨어 설정 변경은 없다.
- 생성 결과: 입력·산출물 해시와 독립 재생성 보고서를 비교한다. 출력 패키지 생성 시각과 미리보기 파일은 검사 복사본에서만 재생성하므로 불필요한 바이너리 변경을 병합하지 않는다.

## 해결한 추가 문제

1. GitHub 검토 의견 [discussion_r4362445495](https://github.com/ckh7488/4leg_robot/pull/1#discussion_r4362445495): 10° 명령에 0.11°만 움직여도 속도가 통과하는 문제. 이전 보완은 전체 성능 미판정만 표시했으므로 충분하지 않았다. 실제 변위/명령 변위가 0.5 미만이면 90% 도달 지표를 null로 만들고 속도 선별도 실패시킨다. 50%는 거의 움직이지 못하는 응답을 제거하는 명시적 연구용 하한이며 정확도 허용 오차가 아니다. design.json에서 조정 가능하다.
2. 관찰창 길이가 표본 간격의 정수배가 아니면 정상 응답도 최종 위치 무효로 처리했다. 경계 직전 표본까지 포함하도록 수정하고 7ms 간격의 정상 응답으로 검증했다.
3. 설계 게인이 400/800/1600/3200 목록 밖이면 게인 비교의 기준 행 검색이 실패했다. 현재 설계 게인을 비교 목록에 자동 포함하도록 수정했다.

양방향 0.11°/0.2°/4.99° 도달량 거부, 50% 경계와 설정 변경, 관찰창·진동·드리프트·선행 정지 실패를 포함한 회귀검사 18개가 통과했다. 원 제안의 수치 비교와 설계 게인 P 400의 목표 미달은 유지된다.
