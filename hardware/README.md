# 하드웨어 미결 항목

상태: 설계 전. 이 폴더에는 아직 BOM·배선도가 없다. 아래 항목이 정해지기 전에는 예산(R1)·무게(R2)·전원(R7) 충족을 주장하지 않는다.

## 5V 모터 전원

| 항목 | 값 | 상태 |
|---|---|---|
| 모터 레일 전압 | 5V 정전압 | 결정 (design.json motor.supply_v) |
| 모터 1개 정지 토크 전류 (5V) | 1.47A | reference: ROBOTIS e-Manual (design.json sources R02) |
| 12개 동시 정지 토크 상한 | 약 17.6A | 계산값, 최악 조건 상한 |
| 보행 중 레일 전류 | 없음 | unmeasured |
| 레귤레이터 부품 | 없음 | blocked, 미선정. CAD에는 46×31×10mm·27g 자리만 있음 |
| 배터리 | 2S 가정, 58×32×22mm·55g 자리 | 미선정. 모터 직결 금지(README) |
| 배선 굵기·커넥터·퓨즈 | 없음 | 미선정 |

판단할 점:
- 상한 17.6A를 그대로 설계 전류로 삼을지, 전류 제한(Current Limit 레지스터)·보행 중 측정값으로 설계 전류를 낮출지.
- 2S → 5V 강압의 손실열과 전압 강하가 모터 응답(BAM 입력 전압)에 주는 영향.
- 두 버스(버스당 모터 6개)의 전원 분기 방식.

## 부품표(BOM)

현재 확인된 비용은 모터 14개(예비 2개 포함) 369,600원뿐이다(README). SBC·MCU·IMU·배터리·레귤레이터·나사·베어링/아이들러·배선·출력 재료·배송·재출력 예비는 미정이다.
